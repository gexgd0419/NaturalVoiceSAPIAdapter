# Edge Sec-MS-GEC v2 regression tests

Based on v0.2.9 (`7194eca5b78d8e477793c159d731d62b6357ffbf`).
The pinned edge-tts 7.3.0 reference and its license are in `reference/`.

The v2 implementation ports the modified SHA-256 and CS64 digest. It retains
server Date clock correction and rounds integer FILETIME values down to
five-minute windows. The protocol version and User-Agent match edge-tts 7.3.0.
Additional Edge handshake headers are restricted to the official Edge endpoint.
Local SDK initialization, Azure subscription authentication, SSML, decoding
and SAPI event conversion are unchanged.

## Build without registration

Run from the repository root in a Visual Studio Developer PowerShell:

```powershell
msbuild NaturalVoiceSAPIAdapter.sln /t:NaturalVoiceSAPIAdapter /m /p:Configuration=Release /p:Platform=x64 /p:NaturalVoiceRegisterOutput=false
msbuild NaturalVoiceSAPIAdapter.sln /t:NaturalVoiceSAPIAdapter /m /p:Configuration=Release /p:Platform=x86 /p:NaturalVoiceRegisterOutput=false
```

The registration option preserves the existing default (`true`). Always pass
`NaturalVoiceRegisterOutput=false` when testing without installation.
The test machine used `/p:PlatformToolset=v145 /p:PreferredToolArchitecture=x64`
because its v143 installation lacked ATL.

## Offline algorithm comparison

```powershell
cl /nologo /EHsc /W4 /std:c++17 tests\gec_cli.cpp /Fe:tests\gec_cli.exe /Fo:tests\gec_cli.obj
python tests\test_gec.py
```

Python 3.10 or later is required; no Python dependencies need to be installed.
This compares compiled production code with the pinned reference, including
random timestamps, five-minute boundaries and uint64 extremes.

## Direct SAPI engine smoke test

```powershell
cl /nologo /EHsc /W4 /std:c++17 /utf-8 tests\sapi_smoke.cpp /Fe:tests\sapi_smoke.exe /Fo:tests\sapi_smoke.obj ole32.lib sapi.lib uuid.lib
 tests\sapi_smoke.exe "$PWD\x64\Release\NaturalVoiceSAPIAdapter.dll" en-US-AriaNeural 60000 tests\english.wav
 tests\sapi_smoke.exe "$PWD\x64\Release\NaturalVoiceSAPIAdapter.dll" zh-CN-XiaoxiaoNeural 60000 tests\chinese.wav
 tests\sapi_smoke.exe "$PWD\x64\Release\NaturalVoiceSAPIAdapter.dll" local 60000 tests\local.wav
 tests\sapi_smoke.exe "$PWD\x64\Release\NaturalVoiceSAPIAdapter.dll" en-US-AriaNeural 100
```

This executable uses LoadLibraryEx / DllGetClassObject and online tokens in
memory. It does not register the engine or run the installer. The local mode
reads existing voices and reports SKIP when none are available; it never
downloads voice packs or changes settings.

For x86 testing, compile in an x64_x86 Developer environment using output name
sapi_smoke_x86.exe, then load Release\NaturalVoiceSAPIAdapter.dll. Process and
DLL architectures must match. Audio is 24 kHz, 16-bit mono WAV.
